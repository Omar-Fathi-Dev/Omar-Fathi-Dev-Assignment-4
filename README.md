## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Omar-Fathi-Dev/Omar-Fathi-Dev-Assignment-4.git
```

2. Open the repository folder:

```bash
cd Omar-Fathi-Dev-Assignment-4
```

3. Open the `AcademyScheduleAnalyzer` project folder:

```bash
cd AcademyScheduleAnalyzer/AcademyScheduleAnalyzer
```

4. Restore the project dependencies:

```bash
dotnet restore
```

5. Build the project:

```bash
dotnet build
```

6. Run the console application:

```bash
dotnet run
```

7. The Academy Schedule Analyzer menu will appear in the console.

8. Choose an option from the menu by entering its number.

9. Choose `0` to exit the application.
